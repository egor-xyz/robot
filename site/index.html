install in Claude Code

Two lines.
Restart. Done.

macOS, Linux and Windows. No daemon, no network, nothing else to install.

  1. 1
    Add the marketplace, in the Claude Code prompt/plugin marketplace add egor-xyz/robot
  2. 2
    Install the robot/plugin install robot@robot
  3. 3
    Restart Claude CodeThe robot appears above the prompt.
/robot

Hide or show the robot.

/plugin → robot → Configure

Turn the fire off, or set when it starts.

/plugin update robot@robot
